# sigbot: сигнальный бот по топ 30 USDT перпетуалам

Статус: ядро (журнал, риск, индикаторы, сверка текста). Сборщик, бэктест, сканер, публикация в работе.

## Решения владельца и допущения
- Текст пишет Gemini (бесплатный тариф). Числа в пост подставляет шаблон, комментарий модели без цифр, итоговый текст сверяется с числами движка.
- Режим paper не блокирует канал: сигналы публикуются сразу, в журнале помечены `mode=paper`. Пауза и kill switch остаются.
- CVD (спот и фьючерсы отдельно), карта ликвидаций, дивергенции (регулярные и скрытые, бычьи и медвежьи) против RSI, CVD спота, CVD фьючерсов и OI.
- Карта ликвидаций: оценка по приросту OI (плечи 10/25/50/100) плюс собственная запись потока ликвидаций. Поток Binance отдаёт не все ликвидации, а снимок раз в секунду на символ, поэтому это нижняя оценка.
- Источник данных на старте: Binance (фьючерсы и спот), премиум Coinbase по BTC как общий фон рынка, индекс страха и жадности.
